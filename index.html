Installation Guide

1

Install R Environment

Download and install R from CRAN or use your system's package manager:

# Ubuntu/Debian sudo apt-get update sudo apt-get install r-base r-base-dev # macOS with Homebrew brew install r # Windows: Download from https://cran.r-project.org/
2

Install Required R Packages

Run the setup script to install all necessary packages:

# Navigate to the project directory cd /path/to/OKComputer_R-Dashboard-App # Run the setup script Rscript setup.R
3

Verify Installation

Test the installation with the provided test script:

# Run the test script Rscript test_setup.R # Or test interactively in R source("test_setup.R")
4

Launch the Dashboard

Start the Shiny application:

# Method 1: Using Rscript Rscript -e "shiny::runApp('app.R', port=3838, launch.browser=TRUE)" # Method 2: Interactive R session R > library(shiny) > runApp('app.R')
5

Access the Dashboard

Once running, the dashboard will be accessible at:

# Local access http://localhost:3838 # Network access (if configured) http://[your-ip-address]:3838

Troubleshooting

Common Issues & Solutions:

Package Installation Errors:

# Install missing packages manually install.packages(c("shiny", "shinydashboard", "tidyverse", "plotly")) # For sunburstR and parcoords, you may need: install.packages(c("sunburstR", "parcoords"), dependencies=TRUE)

Port Already in Use:

# Use a different port shiny::runApp('app.R', port=3839) # Or let Shiny choose an available port shiny::runApp('app.R', port=0)

Permission Issues:

# Check file permissions ls -la app.R setup.R # Make scripts executable (if needed) chmod +x setup.R test_setup.R
